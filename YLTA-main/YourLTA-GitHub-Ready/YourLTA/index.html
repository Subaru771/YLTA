Before you import · Privacy & source

On phone: Web import transmits your NPSSO credential over HTTPS to the YourLTA-operated server on Render, which requests trophies from PSN. This is unofficial account access; NPSSO is a sensitive credential. The supplied server code does not intentionally save tokens or log request bodies. This is not a guarantee about hosting infrastructure or the deployed service.

On Windows PC: Download and run the local exporter, then import its JSON file. This avoids sending NPSSO to YourLTA's import server; the exporter still communicates with Sony using unofficial access.

After import: Review and apply your trophies. Collection data and goals are saved in this browser, with no automatic cloud sync. Export a JSON backup before clearing site data or moving devices.

◇Windows warning? Verify the exporter before running it.

The exporter is a downloadable CMD + JavaScript utility, not a signed Windows application. Windows may flag scripts downloaded from the internet, including legitimate ones. A warning is a reason to inspect the file, not proof that it is safe or unsafe.

What it does: opens Sony's sign-in and NPSSO pages, uses the token you enter locally to request trophy data, and writes JSON/CSV files on your computer. It does not automatically send your token or trophy file to YourLTA. YourLTA imports the JSON you select manually.

The exporter uses the community psn-api npm dependency, which also runs code. Source inspection and a matching checksum are useful transparency measures, but neither is a malware-free certification.

Verify your ZIP with SHA-256

On Windows, open PowerShell in the folder containing the downloaded ZIP, then run:

Get-FileHash -Algorithm SHA256 -LiteralPath ".\ylta-psn-sync-kit.zip"

Expected SHA-256 for this release:

fc4a6fd937eb2a3c9e144e9b2ed1bd933f6155933b1ceff0bb26dcf75d2fa84f

If the hash does not match, do not run the file. This checksum verifies a match with the file published here; it does not independently establish safety.

If Windows says “These files can't be opened”
  1. Confirm you downloaded the exporter from the YourLTA website and review the source above.
  2. Right-click the downloaded ZIP → Properties. If an Unblock option is shown, use it only if you have inspected and trust the file.
  3. Extract the ZIP again, then try the launcher. If it is still blocked, stop rather than disabling Windows security settings.

Unblocking is an explicit trust decision. You never need to turn off Windows Defender, SmartScreen, or antivirus protection to use the YourLTA website.

How to install and capture several games
  1. Extract the downloaded ZIP to a permanent folder.
  2. Open brave://extensions or chrome://extensions, enable Developer mode and choose Load unpacked.
  3. Select the extracted folder containing manifest.json.
  4. Open multiple PSNProfiles game trophy-list pages in tabs. Click the YLTA extension icon → Capture all open trophy tabs.
  5. Repeat for more games, then choose Export YLTA import file (.json).
  6. Choose that JSON below → Analyze → review matches → Apply.

The helper reads only trophy pages you already have open, at your request. It does not automatically download your entire collection or evade blocked pages.
