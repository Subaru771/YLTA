# Upload YourLTA to GitHub

1. Extract this ZIP. Open the `YourLTA` folder.
2. Open your GitHub repository. Use **Add file → Upload files**.
3. Drag the contents of `YourLTA` into the upload area—not the ZIP or its outer folder. `README.md` and `index.html` should appear at the repository root.
4. Include `.github` and `.gitignore`; on Windows, enable hidden items if necessary. They provide issue templates and local-file exclusions.
5. If GitHub reports a README conflict with its generated starter file, replace that starter README with the supplied one. Do not delete any unrelated existing work.
6. Review the upload list, use commit message `Add YourLTA v56 source and documentation`, and commit through the UI. If your repository requires a branch, open a pull request.
7. Set the repository About description to `Free PlayStation trophy stats, rarity comparisons, personal goals and hunter cards.` Set Website to `https://yourlta.pages.dev/`.
8. Check that Issues is enabled. Consider enabling private vulnerability reporting through repository settings before inviting security reports.

Keep Cloudflare hosting. No GitHub Pages or automatic deployment has been configured.

This package contains the v56 app and supplied original feature reel. The separately slowed reel was not substituted into the website. No license has been selected. No repository has been created, uploaded to or changed by this preparation.

The package has 80 repository files and every file is below 25 MiB, compatible with the documented browser upload limits at preparation time. If the browser omits folders, use GitHub Desktop or upload them separately while preserving their paths.

Official upload documentation: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
