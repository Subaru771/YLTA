# Contributing

Thanks for helping improve YourLTA. For a bug, explain the device/browser, import method, exact steps, expected behavior and actual behavior. Redact credentials and private account information. Do not attach an unreviewed full collection export.

Feature requests should describe a trophy-hunting task and why the current app does not meet it. For code changes, keep scope focused, explain the user-visible result and record how it was checked. Preserve existing collection data and the distinction between PSN and PSNProfiles rarity.

Run `node --check` on changed JavaScript files. Test affected behavior in a browser; import changes need a representative import/review/apply check. Do not make automated calls to the live import service merely to test formatting or unrelated UI changes.

No project license has been selected yet. Before making a substantial code contribution, clarify contribution and licensing terms with the owner in an issue.
