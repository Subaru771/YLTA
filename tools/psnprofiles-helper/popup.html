How to use
  1. Open PSNProfiles and visit a game's Trophies page.
  2. Click Capture current game tab, or open several game pages in different tabs and use Capture all open trophy tabs.
  3. Repeat with more pages if needed, then click Export.
  4. In YLTA → Import / Export → PSNProfiles, select the exported JSON and review matches before applying.

Each game's percentage is a snapshot from the page when you captured it. This tool cannot automatically retrieve an entire profile.
